# Chord Transposer

A PWA that transposes songs, shows chord references, and piano diagrams.

Built with HTML, CSS, and JavaScript.

To run this -> open terminal from root folder of the project, then use command - 
python -m http.server 8000

Expected output:s
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
