🎹 Chord Transposer (Beginner-Friendly)
What this app does

Lets you paste a song with chords

Transposes it to any key (major or minor)

Shows which notes make up each chord

Works offline

Can be installed like a mobile app

Example

Input
G        D
I love You Lord
Em       C
You are good

Transpose to C#

Output
C#       G#
I love You Lord
A#m      F#
You are good

Chord Reference (What it means)
C# → C#, F, G#
G# → G#, C, D#
A#m → A#, C#, F
F# → F#, A#, C#

This tells you:

Which piano keys to press

Which notes are in each chord

Who this is for

🎹 Piano players

🎸 Guitar players (capo support can be added later)

🎼 Worship leaders / singers

👩‍💻 Beginners learning how music apps work

What this app does NOT do

It does not auto-compose music

It does not guess chords

It does not require internet
